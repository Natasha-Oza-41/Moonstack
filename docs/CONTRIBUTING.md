# Contributing

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Guidelines

- Keep features modular.
- Do not add more logic to `App.jsx` long term.
- Prefer reusable components.
- Keep database writes behind helper functions.
- Preserve user data.
- Avoid storing secrets in frontend env variables.

## Suggested Branch Names

- `feature/roadmap-engine`
- `feature/dsa-operating-system`
- `feature/app-shell-redesign`
- `docs/project-architecture`
