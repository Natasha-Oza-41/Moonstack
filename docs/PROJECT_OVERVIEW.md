# Moonstack Project Overview

Moonstack is a personal operating system for ambitious students, engineers, developers, and builders.

Its purpose is to connect planning with execution:

- Roadmaps become dated tasks.
- DSA practice becomes tracked interview preparation.
- Projects become documented proof-of-work.
- Notes become a second brain.
- GitHub activity becomes visible career evidence.
- Health and consistency become part of the productivity loop.

## Product Direction

Moonstack should feel closer to Linear, Notion, Raycast, Vercel Dashboard, GitHub, and Arc Browser than a basic CRUD dashboard.

The product language should be:

- focused
- dense but calm
- premium dark UI
- fast interactions
- clear hierarchy
- visible progress
- reusable systems

## Current Status

Moonstack has been rebuilt as a Next.js + TypeScript modular application with TailwindCSS, Framer Motion, Zustand, TanStack Query, Recharts, Supabase, and a Supabase Edge Function for GitHub commits.

## Long-Term Vision

Moonstack can evolve into a SaaS-style builder platform with:

- user accounts
- roadmap templates
- DSA sheets
- GitHub proof exports
- AI suggestions
- analytics
- revision systems
- portfolio generation
