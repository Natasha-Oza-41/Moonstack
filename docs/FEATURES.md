# Features

## Dashboard

Shows tasks, study stats, GitHub activity, XP, and progress signals.

## Daily Planner

Supports:

- manual tasks
- priority
- tags
- duplicate prevention
- select all
- delete selected
- remove duplicates

## Calendar

Supports date-wise tasks and monthly progress.

## Career Roadmaps

Supports:

- roadmap links
- generated phases
- dated daily tasks
- adding day tasks
- adding full phase tasks
- saved roadmap plans via `roadmap_sources`

## DSA Tracker

Supports:

- topic/pattern
- problem URL
- platform
- difficulty
- status
- confidence
- solution notes
- Striver starter import
- GitHub markdown commit

## Projects

Supports:

- tech stack
- architecture
- features
- README
- GitHub repo link
- README commit

## Notes Vault

Supports:

- topic folders
- note files
- markdown snippets
- Mermaid snippets
- code/table/bullet snippets

## Health Monitor

Supports:

- mood
- sleep
- water
- activities
- daily notes
